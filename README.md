# Wireshark-Network-Traffic-Analysis-Packet-Investigation
This project demonstrates my hands-on experience using Wireshark to capture, inspect, and analyze network traffic at the packet level.
Wireshark Network Traffic Analysis & Packet Investigation

Project Overview

The objective was to understand how network communications appear during packet capture and to investigate different protocols involved in normal network activity.

What I Analyzed

1. DNS Traffic

I examined DNS queries and responses generated during network communication.

I focused on:

- Source and destination IP addresses
- DNS query names
- DNS responses
- A and AAAA records
- DNS request/response relationships
- Repeated DNS activity

This provided practical experience in understanding how hosts resolve domain names before establishing connections.

2. TCP Traffic

I analyzed TCP communications between internal and external hosts.

Areas examined included:

- Source and destination IP addresses
- Source and destination ports
- TCP connection activity
- SYN/ACK communication
- ACK packets
- Packet sequence information
- TCP connection behavior

3. TLS Traffic

I also inspected TLS traffic and observed encrypted communication between hosts.

The analysis included identifying:

- TLS protocol traffic
- Client Hello activity
- Server communication
- Encrypted application traffic
- Source/destination information

Because TLS encrypts application data, the packet capture demonstrates the importance of understanding network metadata and connection behavior during security investigations.
